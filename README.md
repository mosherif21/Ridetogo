# 🚗 Ridetogo Car Pooling App

## Overview
The Car Pooling App is an Android mobile application built with Java, Kotlin, Firebase, and Google Maps. It enables users to create, join, and share rides with others to reduce travel costs and improve commuting efficiency.

## Tech Stack
- **Java/Kotlin**: Native Android development.
- **Firebase Authentication**: For user login and signup.
- **Firebase Realtime Database**: Manage rides, users, and bookings.
- **Google Maps API**: Display routes, pickup, and drop-off locations.

## Features
- 👤 **User Profiles**: Create and manage accounts with Firebase Auth.
- 🚘 **Ride Creation**: Post available rides with details like route, time, and cost.
- 📍 **Ride Search & Join**: Find and join rides based on location and availability.
- 🗺️ **Map Integration**: Show pickup and drop-off points with Google Maps.
- 🔔 **Notifications**: Get updates about ride availability or changes.

## Installation & Usage
1. Clone the repository.
2. Open in Android Studio.
3. Set up Firebase and Google Maps API key.
4. Run the project on an Android device or emulator.
